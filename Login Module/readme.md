To Learn this Module, you need to run this command in your terminal:

```bash 

pip install Flask PyJWT flask-cors

```

why we need to install these packages?
- Flask: It is a micro web framework written in Python. It is used to create web applications and APIs. In this module, we will use Flask to create a simple web server that will handle user authentication and authorization.
- PyJWT: It is a Python library for encoding and decoding JSON Web Tokens (JWTs). We will use it to create and verify JWTs for user authentication.
- flask-cors: It is a Flask extension that adds support for Cross-Origin Resource Sharing (CORS). We will use it to allow our API to be accessed from different domains.                    


Then, you can run the app.py file to start the server:

```bash

python app.py

```
